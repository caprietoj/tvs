# 🔄 GUÍA: CAMBIOS EN .ENV PARA PASAR DE PRUEBAS A PRODUCCIÓN

## 🎯 OBJETIVO
Esta guía explica **EXACTAMENTE** qué cambios hacer en el archivo `.env` para migrar desde correos de prueba (desarrollo/local) a correos reales (producción).

---

## 📧 DIFERENCIAS ENTRE ENTORNOS

### 🧪 **DESARROLLO/LOCAL (ACTUAL)**
- Correos de prueba: `@test.com`
- Compras: `compras@test.com`
- Configuración: `section-mail-test`

### 🏭 **PRODUCCIÓN**
- Correos reales: `@tvs.edu.co`
- Compras: `compras@tvs.edu.co`
- Configuración: `section_emails`

## 🔧 CAMBIOS REQUERIDOS EN .ENV

### 1. **CAMBIAR ENTORNO DE APLICACIÓN**

```bash
# ANTES (Desarrollo)
APP_ENV=local
APP_DEBUG=false

# DESPUÉS (Producción)
APP_ENV=production
APP_DEBUG=false
```

### 2. **DESACTIVAR MODO DE PRUEBAS**

```bash
# ANTES (Correos de prueba activos)
EMAIL_TEST_MODE=true
PURCHASE_REQUEST_TEST_MODE=true
SECTION_EMAILS_CONFIG=section-mail-test

# DESPUÉS (Correos reales activos)
EMAIL_TEST_MODE=false
PURCHASE_REQUEST_TEST_MODE=false
SECTION_EMAILS_CONFIG=section_emails
```

### 3. **VERIFICAR URL DE APLICACIÓN**

```bash
# DESARROLLO
APP_URL=http://intranet.tvs.edu.co

# PRODUCCIÓN (verificar que sea correcta)
APP_URL=https://intranet.tvs.edu.co
```

### 4. **MANTENER CONFIGURACIÓN DE CORREOS**


## ⚡ PASOS PARA APLICAR LOS CAMBIOS

### 1. **Hacer backup del .env actual**
```bash
cp .env .env.backup
```

### 2. **Editar las líneas específicas**
```bash
# Cambiar estas líneas exactas:
APP_ENV=production
EMAIL_TEST_MODE=false
PURCHASE_REQUEST_TEST_MODE=false
SECTION_EMAILS_CONFIG=section_emails
```

### 3. **Limpiar cachés después del cambio**
```bash
php artisan config:clear
php artisan cache:clear
php artisan view:clear
```

### 4. **Verificar configuración aplicada**
```bash
php artisan config:show app.env
php artisan config:show mail
```
